# Things not worth focusing on (per Google's SEO Starter Guide)

Check this before reporting an issue. If your finding is on this list, do not
present it as a problem. Do what is best for the business and users instead.

| Topic | What to tell the user |
|---|---|
| Meta keywords tag | Google does not use it. Remove or ignore; never "optimize" it. |
| Keyword stuffing | Repeating words (even variants) tires users and violates spam policies. Write naturally. |
| Keywords in domain or URL path | Hardly any ranking effect beyond appearing in breadcrumbs. Pick the name that is best for the business. |
| TLD (.com, .org, .guru) | Only matters when targeting a specific country (e.g. a .ch domain for Swiss users), and even then it is a low-impact signal. |
| Minimum or maximum content length | No magic word count. Varied natural wording simply covers more search terms. |
| Subdomains vs subdirectories | Choose what is easiest to manage for the business. |
| PageRank / link counts | One of many signals. Don't obsess over links alone. |
| Duplicate content "penalty" | Not a manual action; just inefficient. Copying others' content is a separate, real issue. |
| Number and order of headings | Good for screen readers (so keep them semantic for accessibility), but irrelevant to Google. No ideal heading count; if it feels like too many, it probably is. |
| E-E-A-T as a ranking factor | It is not one. Still, helpful, reliable, people-first content with credible sources is the goal. |

## Priority order when time is short

1. Page is indexable and renderable (no accidental noindex, CSS/JS not blocked).
2. Content is genuinely useful, original, readable, current.
3. Unique, accurate titles; unique, summarizing meta descriptions.
4. Descriptive link text and image alt text; images near relevant text.
5. One URL per piece of content (redirect or canonical).
6. Descriptive URLs and directory grouping (mostly for large sites).
7. Sitemap and promotion.

## Timing and honesty

- Effects can appear in hours or take months; assess after a few weeks.
- No guarantee a site gets indexed or ranked first. Never promise rankings.
